# Module 11 — Specialized & Emerging Laptop Devices (Perangkat Laptop Khusus, Eksperimental & Inovatif)

## 11.1 Perangkat Layar Fleksibel & Multi-Layar

```
====================================================================================
          EVOLUSI FAKTOR BENTUK LAYAR NON-KONVENSIONAL PADA LAPTOP MODERN
====================================================================================
  [1. Foldable OLED]             [2. Rollable OLED]              [3. Dual-Screen]
  ┌───────────────────┐          ┌───────────────────┐          ┌───────────────────┐
  │                   │          │   Area Ekspansi   │          │   Layar Atas      │
  │  1 Panel OLED     │          │   (16.7" / 8:9)   │          │   (14" OLED)      │
  │  16.3"–17.3"      │          ├───────────────────┤          ├───────────────────┤
  │  Lipat Tengah     │          │   Layar Dasar     │          │   Layar Bawah     │
  │  (Waterdrop Hinge)│          │   (14.0" / 5:4)   │          │   (14" OLED) +    │
  └───────────────────┘          └───────────────────┘          │   KB Magnetis     │
  • Tanpa garis pemisah          • Motor mikro gulung           └───────────────────┘
  • Rawan gores kuku             • Kaca OLED lebih kaku         • 2 panel kaca penuh
```

* **Foldable Display Laptops** (*Lenovo ThinkPad X1 Fold 16, ASUS Zenbook 17 Fold OLED, HP Spectre Foldable*): Panel OLED polimer lentur dengan *waterdrop hinge*; ergonomi pangkuan terbatas dan rentan goresan benda tajam.
* **Rollable Display Laptops** (*Lenovo ThinkBook Plus Gen 6 Rollable*): Clamshell aluminium 1,69 kg dengan *Intel Core Ultra 7 258V* dan motor mikro yang menggulung layar OLED dari **14" (5:4)** menjadi **16,7" (8:9)** secara vertikal sambil mempertahankan keyboard fisik penuh.
* **Full Dual-Screen Laptops** (*ASUS Zenbook Duo UX8406, Lenovo Yoga Book 9i*): Dua panel kaca OLED 14" 120 Hz penuh + keyboard Bluetooth magnetis; kelayakan komersial tinggi dan tahan gores.
